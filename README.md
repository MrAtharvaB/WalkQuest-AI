# 🌱 WalkQuest AI

Turn a walk into an adventure.

WalkQuest AI is a simple AI-powered app that generates fun outdoor walking quests based on location, duration and difficulty.

## ✨ Features

- 🌱 AI-generated walking quests
- 📍 Location selection
- ⏱️ Duration selection
- 🥾 Difficulty selection
- 🎯 4 walking missions
- 🦺 Safety tips
- 🌱 Touch Grass Score
- 🏆 Mission completion tracker
- 💯 100 XP achievement

## 🛠️ Tech Stack

- Python
- Streamlit
- Ollama
- Gemma 3 1B
